# Zey Vision

Eye-friendly, circadian-adaptive design system for the Zey Ecosystem.

- No pure white, no pure black — colors drift gradually with time of day.
- Night stays warm amber, never blue.
- WCAG AA verified, keyboard accessible, screen-reader friendly throughout.
- Zero runtime dependency beyond React (and Tailwind, for styling).
